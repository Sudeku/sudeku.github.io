# Sudeki — worlds within

Static publication of Sudeki, including its interactive worlds and local runtime assets.

- Website: https://sudeki.ru/
- Free HTTPS host: https://sudeku.github.io/
- Published files: repository root, main branch.
- `.nojekyll` keeps the original HTML, JavaScript, models and textures unchanged.

The initial verified export contains 632 files (258,426,067 bytes). The import workflow checks the archive SHA-256 before extracting it. Re-running that importer restores the initial export; use normal commits for later updates.

Existing asset credits remain in ASSET_CREDITS.txt and the accompanying license files.
